# Версионирование конфигурации ЕГЭ

Считай шкалу и структуру экзамена историческими данными, а не вечной константой.
Текущий bootstrap `PRIMARY_TO_SCALED` находится в `config/settings.py`.
Преобразование выполняют `scaled_score` в `apps/engine/forecast.py` и `primary_to_scaled` в `apps/progress/services.py`.

## Шкала по годам

- Конфигурируй `PRIMARY_TO_SCALED` по экзаменационным годам.
- Связывай каждый прогноз и результат пробника с конкретной версией таблицы.
- Не меняй историческую шкалу задним числом.
- При публикации новой шкалы добавляй новую версию, а не перезаписывай старую.
- Храни источник и дату методического подтверждения шкалы.
- Проверяй длину таблицы относительно `MAX_PRIMARY_SCORE`.
- Проверяй диапазон тестового балла и монотонность преобразования.

## Структура экзамена

- Версионируй максимальный первичный балл, состав частей и номера заданий.
- Версионируй критерии ФИПИ для части 2.
- Не применяй новые критерии к уже завершённой экспертной проверке.
- Связывай `Assignment.exam_part`, `max_score` и узлы с версией структуры года.
- Проверяй `KnowledgeNode.ege_task_numbers` в `apps/knowledge/models.py`.
- Не смешивай задания разных структур в одном `MockExam` без явного адаптера.

## Воспроизводимость

- Передавай таблицу в чистый движок явным аргументом.
- Не импортируй настройки Django в `apps/engine/forecast.py`.
- Пиши год и версию шкалы в payload события пересчёта прогноза.
- Сохраняй версию критериев в аудите `ExpertReviewRequest`.
- Документируй изменение результатов на контрольных профилях mastery.

## Запреты

- Не исправляй прошлые баллы массовым пересчётом без подтверждения человека.
- Не хардкодь год в бизнес-логике сервиса.
- Не используй приблизительную таблицу как официальную без явной маркировки.
- Не выдавай прогноз без известной версии экзаменационной конфигурации.

## Проверка

- Проверь монотонность, границы и длину шкалы.
- Проверь неизменность исторической версии.
- Проверь воспроизводимость результата по году.
- Проверь совместимость `apps/mocks/services.py` и `apps/progress/services.py`.
- Проверь миграцию и обратимость при добавлении полей версии.
