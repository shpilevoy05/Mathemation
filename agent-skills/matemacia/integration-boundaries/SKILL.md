# Границы внешних интеграций

Изолируй каждый внешний сервис за собственным адаптером.
Не позволяй формату провайдера проникать в доменные сервисы.
Сохраняй ФЗ-152 и РФ-периметр для ПДн.

## LLM

- Вызывай LLM только через `HintProvider` в `apps/ai_mentor/providers.py`.
- Не меняй `apps/ai_mentor/services.py` при смене YandexGPT, GigaChat или self-host модели.
- Преобразуй внешний ответ в внутренний текст подсказки до доменного гардрейла.
- Используй `MockHintProvider` как безопасный fallback.
- Не логируй API key, Authorization header, промпт с ПДн или сырой ответ.

## Платежи и webhooks

- Создай адаптер провайдера платежей до включения конкретного API в домен.
- Проверяй подпись webhook до обработки.
- Используй стабильный idempotency key провайдера и уникальное ограничение.
- Делай повтор webhook безопасным и возвращай успешный ответ для уже обработанного события.
- Не активируй услугу по клиентскому redirect без серверного подтверждения.
- Не храни реквизиты карты в приложении.

## Видео, push и S3

- Изолируй Kinescope/VK Video за видео-адаптером.
- Изолируй FCM/APNs/SMS/e-mail за notification-адаптером.
- Изолируй РФ S3 за storage backend; не раздавай постоянные публичные URL сканов.
- Используй короткоживущие signed URLs и object-level проверку.
- Делай upload callback и push delivery идемпотентными.
- Не отправляй сканы части 2 в сервис вне разрешённого РФ-периметра.

## Отказы

- Задавай timeout каждому сетевому вызову.
- Повторяй только временные ошибки с backoff и пределом попыток.
- Не повторяй неидемпотентную операцию без ключа.
- Деградируй безопасно: наставник отдаёт mock/эскалацию, а не непроверенный ответ.
- Не блокируй запись попытки из-за отказа аналитики или уведомления.

## Проверка

- Подмени адаптер fake/mock в тесте доменного сервиса.
- Проверь повтор webhook и upload callback.
- Проверь timeout, retry и безопасный fallback.
- Проверь отсутствие секретов и ПДн в логах.
- Подтверди РФ-размещение для сервиса, получающего ПДн.
