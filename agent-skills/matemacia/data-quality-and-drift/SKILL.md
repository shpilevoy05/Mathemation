# Качество данных и дрейф

Считай каждую попытку обязательной строкой будущего ML-датасета.
Проверяй качество на уровне событий, связей и распределений.

## Полнота событий

- Требуй событие `attempt_submitted` для каждой записи `Attempt`.
- Сверяй создание попытки в `apps/practice/services.py` с `apps/events/services.py`.
- Проверяй обязательные `assignment_id`, `node_ids`, `context` и `is_correct`.
- Не допускай успешной попытки без event или event без доменной попытки.
- Отслеживай задержку между доменной записью и событием.
- Проверяй полноту mock, diagnostic, review, hint и trajectory событий.

## Аномалии

- Ищи повторные события одной операции без idempotency key.
- Ищи невозможные значения mastery, difficulty, score и времени.
- Ищи резкие всплески попыток, XP или подсказок как возможный farming/bot.
- Ищи задачи без узлов, узлы без контента и orphan references.
- Ищи неверный порядок: экспертное завершение до submission.
- Не исправляй append-only историю удалением; создавай correction/compensation contract.

## Дрейф

- Сравнивай эмпирическую сложность задач с prior difficulty 1..5.
- Сегментируй по части экзамена, узлу, периоду и первой/повторной попытке.
- Отслеживай дрейф после изменения формулировки задачи или решения.
- Не смешивай шкалы и структуры разных экзаменационных лет.
- Сигнализируй методисту, а не автоматически переписывай difficulty.
- Версионируй подтверждённую перекалибровку.

## Локальный анализ

- Используй DuckDB для локального read-only анализа выгрузок.
- Не добавляй DuckDB в runtime-зависимости без одобрения.
- Работай с обезличенными данными и минимально необходимыми столбцами.
- Не читай `.env` и не выгружай реальные ПДн.
- Сохраняй запросы и контрольные суммы входных файлов для воспроизводимости.

## Проверка

- Построй reconciliation Attempt ↔ `attempt_submitted`.
- Проверь дубликаты, пропуски, диапазоны и временной порядок.
- Построй drift-отчёт по difficulty и частям экзамена.
- Проверь отсутствие ПДн в аналитической выборке.
- Передай подтверждённые аномалии владельцу доменного сервиса.
