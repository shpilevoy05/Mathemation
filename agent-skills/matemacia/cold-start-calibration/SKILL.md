# Холодный старт и калибровка

Исходи из того, что на запуске исторических логов учеников нет.
Используй прозрачные методические приоры до накопления достаточных событий.

## Bootstrap

- Задавай difficulty каждой задачи оценкой методиста в диапазоне 1..5.
- Храни difficulty в `Assignment` из `apps/content/models.py`.
- Инициализируй mastery по диагностике через `apps/diagnostics/services.py`.
- Для непройденных узлов оставляй прозрачный нулевой или утверждённый приор.
- Используй BKT-параметры из `EngineParams`, собранные из `config/settings.py`.
- Используй дефолты decay и review intervals из настроек.
- Не представляй bootstrap-параметры как обученную ML-модель.

## Прогноз

- Строй первичный прогноз через 2PL bootstrap в `apps/engine/forecast.py`.
- Переводи первичный балл годовой таблицей, а не линейной догадкой.
- Калибруй по завершённым пробникам через `calibrate_forecast`.
- Используй EMA с `FORECAST_CALIBRATION_ALPHA`.
- Не калибруй по незавершённому пробнику или только части 1, если часть 2 ожидает эксперта.
- Вызывай калибровку из финализации `apps/mocks/services.py`.

## Переход к данным

- Переходи на data-driven параметры только после накопления event-лога.
- Сначала обеспечь полноту append-only событий через `apps/events/`.
- Определи минимальный объём и покрытие учеников, задач и навыков до переоценки параметров.
- Сравни data-driven параметры с методическими приорами на holdout.
- Не заменяй приоры, если данные покрывают только активных или сильных учеников.
- Не подключай DKT/SAKT до накопления репрезентативной последовательности попыток.
- Версионируй параметры и сохраняй возможность воспроизвести старый прогноз.

## Смещения

- Проверяй различия по части экзамена, сложности, навыку и типу пользователя.
- Отделяй влияние подсказок и повторных попыток от первой независимой попытки.
- Не используй экспертный вердикт до `finish_review` как истинную метку.
- Не смешивай шкалы разных экзаменационных лет.

## Проверка

- Проверь диапазон difficulty 1..5 и методическое происхождение.
- Проверь EMA на последовательности пробников.
- Проверь отсутствие калибровки до финального результата части 2.
- Проверь holdout и сравнение с baseline.
- Проверь версию параметров в артефакте и событии пересчёта.
