# Сократический наставник и RAG

Считай наставника системой помощи, а не генератором решений.
Оркестрируй подсказки в `apps/ai_mentor/services.py` через провайдер `apps/ai_mentor/providers.py`.

## Семь уровней помощи

1. уточнить понятое;
2. напомнить определение;
3. указать на ошибочный шаг;
4. наводящий вопрос;
5. малый промежуточный шаг;
6. аналогичный не идентичный пример;
7. передать человеку.

- Не добавляй финальный ответ как уровень помощи: финальный ответ НЕ является уровнем.
- Повышай уровень только после наблюдаемой потребности ученика.
- Не перескакивай к полному решению после первого затруднения.
- Ограничивай ответ максимум двумя наводящими вопросами.
- После исчерпания допустимых подсказок передавай человеку.

## RAG-граундинг

- Используй только проверенный `Assignment.reference_solution` из `apps/content/models.py`.
- Добавляй релевантную проверенную теорию, а не свободные знания провайдера.
- Не генерируй метод решения, отсутствующий в reference solution.
- При отсутствии разбора помечай неуверенность и предлагай эксперта.
- Редактируй финальный `correct_answer` перед сборкой промпта.
- Не включай заблокированные сообщения в историю контекста.

## Доступность

- Проверяй контекст через `mentor_available`.
- Разрешай наставника только в обычном уроке.
- Отключай его на mock, diagnostic и review.
- Не полагайся только на скрытую кнопку; запрещай запрос на уровне сервиса/API.
- Сверяй контексты с `Attempt.Context` в `apps/practice/models.py`.

## Выход

- Проверяй текст через `check_hint` до сохранения видимого сообщения.
- Проверяй утечку ответа через `contains_final_answer`.
- Помечай непроверенные утверждения `UNCERTAINTY_NOTE`.
- Логируй выданную или заблокированную подсказку через `apps/events/`.

## Проверка

- Проверь все семь уровней и отсутствие восьмого «ответ».
- Проверь не более двух вопросов.
- Проверь grounded-only поведение без reference solution.
- Проверь запрет mock/diagnostic/review на сервисе и API.
