# Ввод и отображение математики

Сохраняй простой школьный ввод без небезопасного исполнения выражений.
Используй нормализацию из `apps/ai_mentor/guardrails.py` и `Assignment.check_answer`.

## Допустимая запись

- Принимай верхние индексы `²` и `³`.
- Принимай квадратный корень `√`.
- Принимай число `π` и LaTeX-подобное `\pi`.
- Принимай степень через `^`.
- Принимай дроби через `/` и конструкцию `\frac{a}{b}`.
- Принимай `\sqrt`, `\sin`, `\cos`, `\tan`, `\log`, `\ln` в текстах.
- Нормализуй умножение `×`, `·`, `\cdot`, `\times`.
- Нормализуй разные Unicode-минусы и деление `÷`.

## Парсинг

- Используй `_normalize_expression` перед `parse_expr`.
- Преобразуй `²`/`³` в безопасные степени и `^` в `**`.
- Преобразуй запятую между цифрами в точку.
- Используй safe globals/locals и белый список функций.
- Разрешай только односимвольные переменные вне списка функций.
- Не используй Python `eval` или необработанный `sympify` с globals процесса.
- Возвращай `None` для непарсируемого выражения, не роняй API.
