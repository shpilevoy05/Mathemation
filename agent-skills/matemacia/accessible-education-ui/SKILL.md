# Доступный образовательный UI

Обеспечь базовую доступность без отдельного «режима».
Считай клавиатуру и screen reader полноценными способами работы.

## Цвет и контраст

- Проверяй WCAG AA для текста на токенах `static/css/app.css`.
- Не используй `--muted` для мелкого текста без проверки контраста.
- Не кодируй mastery, риск или статус только цветом.
- Добавляй подпись, иконку или текстовый статус.
- Проверяй focus outline на `--primary` и `--primary-soft`.
- Не отключай outline без равноценной видимой замены.

## Формы

- Связывай каждый input с видимым `label` через `for`/`id`.
- Показывай ошибку рядом с полем и связывай её через aria-describedby.
- Сохраняй логичный tab order без положительного `tabindex`.
- Обеспечь отправку формы Enter и управление кнопками Space/Enter.
- Не используй placeholder как единственную подпись.
- Объявляй динамический verdict через `aria-live`, как в `templates/lesson.html`.

## SVG и изображения

- Добавляй информативному SVG `role="img"` и `aria-label`.
- Следуй примеру `templates/partials/logo.html`.
- Скрывай декоративный SVG через `aria-hidden="true"`.
- Добавляй содержательный `alt` изображениям решения; не дублируй соседний текст.
- Не помещай критический текст только внутрь изображения.

## Dialog и навигация

- Удерживай focus внутри открытого dialog и возвращай его инициатору после закрытия.
- Поддерживай Escape, если закрытие безопасно.
- Давай dialog доступное имя и описание.
- Обозначай текущий пункт навигации через `aria-current`.
- Сохраняй skip-link или прямой доступ к main content.

## Mobile

- Делай цели нижнего tab-bar и controls не меньше 44×44 px.
- Не ставь соседние destructive и primary цели вплотную.
- Проверяй масштаб текста и reflow без горизонтального scroll.
- Сохраняй читаемый порядок DOM независимо от визуальной сетки.

## Проверка

- Пройди основной путь только клавиатурой.
- Проверь имя/роль/состояние controls screen reader-деревом.
- Проверь AA contrast и 200% zoom.
- Проверь mobile targets и динамические сообщения.
